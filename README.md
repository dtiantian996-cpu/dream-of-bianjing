\# 梦回汴京



《梦回汴京》是一款以北宋文化为主题的沉浸式严肃游戏，由11人团队在14周内使用 Unity3D 开发完成。



项目以北宋都城汴京为主要场景，将人物对话、文物展示和文化小游戏融入游戏流程，使用户能够在探索虚拟场景的过程中了解宋词、宋式美学、市井生活、传统文物及相关历史文化。



\## 项目定位



本项目以“沉浸式场景与宋朝文化传播”为核心，面向学生、传统文化爱好者及宋史爱好者。



项目希望通过游戏化交互降低历史文化的学习门槛，将抽象的知识转化为可以观察、操作和体验的游戏内容，实现寓教于乐的文化传播效果。



\## 主要功能



\### 汴京场景探索



游戏以北宋都城汴京为场景背景，通过建筑、角色、界面和环境设计营造具有宋代特色的视觉氛围。



\### 人物对话



玩家可以与场景中的人物进行互动，通过对话了解：



\- 宋朝市井生活

\- 宋词及其创作背景

\- 朝堂与社会文化

\- 宋代钱币和商业活动

\- 传统生活习俗



\### 文物展示



项目设置了宋朝相关文物展示功能，玩家可以查看文物模型及相关介绍，了解文物的历史背景、艺术特点和制作工艺。



展示内容包括：



\- 莲花碗

\- 瓦当

\- 青铜鼎

\- 菩萨造像

\- 其他宋代代表性文物



\### 文化小游戏



项目将文化知识融入互动玩法，设计了多种小游戏：



\- 诗句填充

\- 文物连连看

\- 文物记忆卡牌

\- 华容道



玩家可以在完成游戏任务的过程中学习和巩固宋朝文化知识。

\## 运行方法



\### 1. 安装开发环境



安装以下软件：



\- Unity Hub

\- Unity Editor

\- Visual Studio 或其他支持 C# 的编辑器



项目使用的具体 Unity 版本可在以下文件中查看：



```text

ProjectSettings/ProjectVersion.txt

```



建议使用相同版本的 Unity Editor 打开项目，以减少资源重新导入或版本兼容问题。



\### 2. 下载项目



使用 Git 克隆仓库：



```bash

git clone 你的GitHub仓库地址

```



也可以在 GitHub 页面选择：



```text

Code → Download ZIP

```



\### 3. 导入 Unity



1\. 打开 Unity Hub。

2\. 点击“添加”或“Add project from disk”。

3\. 选择项目根目录 `Gujianzhu`。

4\. 使用对应版本的 Unity Editor 打开项目。

5\. 等待 Unity 自动导入资源并恢复软件包。



首次打开时，Unity 会重新生成 `Library`、`Logs`、解决方案和项目文件，因此加载时间可能较长。



\### 4. 运行游戏



1\. 在 Unity 的 `Assets` 目录中找到项目主场景。

2\. 双击打开主场景。

3\. 点击编辑器顶部的运行按钮。

4\. 根据游戏界面提示进行探索、对话和小游戏体验。
